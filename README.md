# 🎬 Netflix Frontend Clone

A Netflix-inspired frontend website built using HTML and CSS.  
This project focuses on recreating the visual design and layout of a modern streaming platform.

## 📌 Project Overview

This project is a frontend implementation inspired by the Netflix streaming platform.

It demonstrates the use of HTML and CSS to create a structured, visually appealing entertainment website with a Netflix-style interface.

## 🛠️ Technologies Used

- HTML5
- CSS3

## ✨ Features

- Netflix-inspired user interface
- Responsive webpage layout
- Navigation bar
- Hero/banner section
- Movie and TV show sections
- Movie cards and thumbnails
- Hover effects
- Custom CSS styling
- Clean and organized frontend structure
